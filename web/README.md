# web

Empty until the schema's stable. Once it is, this becomes a Next.js app: Tailwind for styling, Tremor/ECharts for the visuals, Zustand for cross-filter state, DuckDB-wasm reading Parquet from `data/exports` directly in the browser — no backend server.

See `docs/decisions/0002-web-stack-simplification.md` for why it's built this way.
